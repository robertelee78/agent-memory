# Private ancestors are part of cache-directory eligibility

Agent Memory’s Unix lifecycle policy evaluates reachability from root to leaf. A verified current-user-owned 0700 ancestor protects current-owner 0775 or 0777 cache directories beneath it; directory mode bits alone do not establish that other principals can reach the directory. A private child cannot rescue a reachable writable ancestor, and foreign ownership remains refused.

A cache-recovery regression came from adding a blanket directory-mode check after the shared path policy had already qualified the private tree. Real Python cache creation under umask 0002 produces 0775 directories and 0644 cache files, so fixtures limited to restrictive synthetic directories miss this layout. This path qualification does not authenticate opaque cache bytes or relax signed-payload identity, owner, link, file-mode, inventory or transaction checks.
