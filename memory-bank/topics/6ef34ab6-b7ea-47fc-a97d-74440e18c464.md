# Large-worktree updater incident

During the operator’s v0.0.2-to-v0.0.3 upgrade, am update took 6 minutes 25 seconds on macOS. A later read-only profile observed 598 available worktrees, 144 banks and 70 discovery gaps; the updater repeats compatibility observations around activation. This is a historical incident and a single-pass profile, not a claim that all elapsed time came from one function or that later versions have the same latency.
