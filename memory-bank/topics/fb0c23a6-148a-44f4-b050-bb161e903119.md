# Native lifecycle IDs do not identify individual callback observations

For this repository’s harness-boundary design and qualification, native session, turn and prompt IDs correlate lifecycle; they do not establish unique callback submissions. Real Codex 0.165.0 steering and Claude Code 2.1.306 streamed callbacks reused a native lifecycle ID for distinct and identical follow-ups. Preserve each observed callback separately with its immutable source digest; an earlier assessment must not cover a later identical-text observation. A digest binds bytes, not the surrounding conversational meaning.

Do not infer a unique callback identity from a private transcript projection: that projection can lag or collapse multiple native callbacks. Use the native adapter’s actual source witness and retain attribution. An interrupted observation whose original source cannot be recovered and matched remains pending; a new prompt or a guessed no-learning assessment cannot complete it.

This is a reviewed engineering lesson from ADR-0020 and the linked native proofs, not a claim that another harness repeats IDs, that current code has landed, or that source assessment establishes semantic completeness, admission or publication.
