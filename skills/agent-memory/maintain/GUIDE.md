# Maintain project memory

Keep existing learning concise and reachable, preserving distinct conditions, evidence and origins. Derived references remain replaceable and never become the only current copy.

A session MUST load this domain before its selected operation leaf and MUST NOT
preload sibling leaves for completeness. It MUST return to observed state before
selecting another operation. It MUST open the [shared model](../model/GUIDE.md)
only when a scope, authority, type, trust, lifecycle, validity or contradiction
question cannot be resolved by this domain and the selected operation.

## Standing rules

A session MUST follow [consolidation/GUIDE.md](../consolidation/GUIDE.md) at natural
turn boundaries when comparison identifies equivalent learning or wording to
tighten. It MUST preserve every distinct condition, evidence source and origin,
retain useful history, and leave unresolved changes of meaning for clarification.

A session MUST read [layout/GUIDE.md](../layout/GUIDE.md) when adding or inspecting
optional records, maintaining topic indexes, or resolving missing, duplicate or
inconsistent routes. Index routing MUST preserve each lesson's own conditions.
