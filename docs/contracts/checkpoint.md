# Single-file mediated checkpoint

The portable [checkpoint guide](../../skills/agent-memory/checkpoint/GUIDE.md)
defines inspect, reviewed fields, preview/apply, omitted-context preparation and
recovery. Checkout and copied pack expose the same `scripts/checkpoint.py`.

The helper captures current focus, meaningful recent changes, open questions and
the next concrete step. It preserves unrecognized sections, source conditions,
provenance notes and fenced examples. A complete observed active hash and pinned
scope bind the proposal. It validates that the intended replacement matches the
reviewed input and base text, then delegates to the common lock, atomic
single-file replacement, readback and private receipt mechanism.

The only canonical checkpoint target is `activeContext.md`. Progress, topics
and router edits are separate. An omitted active context has an explicit
read-only preparation path returning a separate observed multi-file proposal;
it never hides a router change inside the single-file operation. Existing code,
index and HEAD remain intact. Verification is local, not publication or proof
of the truth of arbitrary prose.
