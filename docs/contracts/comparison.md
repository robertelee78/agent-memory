# Search/read before durable learning and landing

The [portable comparison guide](../../skills/agent-memory/comparison/GUIDE.md)
requires ordinary same-concept/alternative search, inspection of plausible
canonical sources and explicit agent judgment before a durable learning change.
The public helper binds request, router and whole-bank observation hashes to a
complete bounded match list. It considers other conditions and inactive states
as data for comparison, without presenting them as current guidance.

Review classifies every plausible source against its exact observation. Equivalent
learning reuses existing identities; different conditions/types cannot silently
merge. The plan retains full metadata, evidence and originating provenance.
Contradictions, uncertainty and inactive equivalents require clarification or
lifecycle review. The helper never decides semantic truth, performs mutation or
claims that a structurally valid judgment proves its agent understood the sources.

Check repeats inspection and refuses changed candidates, source observations,
match sets and proof bytes. An unavailable/interrupted/oversized bank cannot mean
no match, and terminal deleted identities cannot reenter as candidate/derivation
sources. A writer must revalidate against its locked bank, and publication must
repeat comparison against actually refreshed latest landed memory. This helper
only observes local canonical bytes; it does not fetch or claim main freshness.

Public copied-pack cases cover paraphrases, similar-but-distinct knowledge,
different conditions, concurrent duplicate arrival, complete classifications,
strict proof comparison, unsafe/unavailable sources, review budgets, deletion,
inactive equivalence and detecting-developer conflict handling. Optional indexes
are unnecessary. Private content-free audit is separate from canonical bank/Git
writes, of which these operations perform none.
