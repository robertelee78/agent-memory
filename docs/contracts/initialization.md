# Evidence-led initialization

The portable [initialization guide](../../skills/agent-memory/initialize/GUIDE.md)
defines the ordered existing-memory/source inspection, AWA skill handoff,
reviewed interpretation, focused product questions and observed apply workflow.
The checkout and copied artifact both expose `scripts/initialize.py`.

The helper inventories bounded local documentation/planning/code/test sources,
respects Git ignore rules, and reports incomplete coverage explicitly. AWA work
references come from the AWA skill, with explicit unavailable evidence gaps.
Source existence does not prove intent, passing tests or delivery. The session
reviews actual source content before qualifying comparable assertions.

Generated Markdown is a concise source-linked orientation map. Qualified claims
retain their authority domain and conditions. Disagreeing peers on one precise
question become detecting-developer questions; unfinished implementation that
differs from approved intent stays a distinct implementation gap. No source
parser claims semantic interpretation or authentication.

Existing memory is inspected first and preserved byte for byte. Initialization
can add useful missing context and routes, with no empty placeholders. Sources,
handoff bytes, identity and bank observation are checked before mutation. First
creation uses the same private journal/visible marker/router-last transaction
as an existing bank. The explicit initialization-only identity handoff prevents
a circular requirement for a bank before setup can create one. Interrupted
first creation can finish or roll back to an uninitialized checkout, preserving
unrelated code, index and HEAD. The original source/review evidence remains in
the private transaction journal and is checked again before recovery finish,
including under the bank lock. Changed source bytes, branch, HEAD or AWA handoff
stop finish; known-base rollback remains available. A legacy initialization
journal without that proof can roll back but cannot finish. Branch/revision
claims must match known inspected context, and encoded local evidence links
resolve exact paths containing spaces, Unicode or URL punctuation.

Local verified creation is not publication, admission of arbitrary source text,
remote freshness or release proof. Broader governed capture/security/sharing and
installed lifecycle contracts have separate milestone stories.
