# Project-bound baseline retrieval

The portable [recall guide](../../skills/agent-memory/retrieval/GUIDE.md) teaches
the public `retrieve.py --repo … --request …` operation. It resolves the actual
bank, inherited scope and observed Git context before ranking typed current
records, using exact IDs/paths or ordinary text without optional stores. Active
lifecycle, validity, trust, visibility, type, applicability and canonical
replacement checks remain hard filters. Unknown conditions cannot become current
guidance; neither exact matching nor confidence overrides a failed gate.

Ordinary context is an explicit orientation option, separately labeled with
unknown trust. It does not fabricate typed admission. Selected content retains
conditions, evidence, source hashes and origin identity across clones. Source
labels are unverified data. A quarantined replacement cannot reactivate its
obsolete predecessor, and terminal tombstones cannot be bypassed by old cached
content. Exclusion counts do not disclose withheld bodies or names.

The helper checks canonical observations again, reports actual evaluation time
and bounded payload/reader metrics, and writes a private content-free audit.
It preserves code, HEAD, index and canonical bank bytes. Complete-bank hashing
still scales with bank size. A result is neither an atomic lasting snapshot nor
proof of evidence truth, admission, publication or current working-code behavior.
Callers must re-evaluate changed/time-sensitive evidence and observe write-lock
revalidation when proposing mutations. Contradictions remain the detecting
session's responsibility; this operation does not perform semantic admission or
automated source reconciliation.

Public contract cases use a copied skill, actual Git branches/detached HEAD,
independent local clones/developers, nested routes, lifecycle/security exclusions,
canonical tombstones, optional-index loss and whole-record result budgets. They
do not establish cross-machine automatic sharing or a retrieval quality/latency
target for a large bank; those require later measured workloads.
