# v0.0.2 corrective release

This release repairs the initial public installation and command experience.
The product contract is [ADR-0013](../adr/0013-public-cli-and-corrective-releases.md).
It includes the one-line bootstrap (#153), native macOS temporary-path and owned
`am` fixes (#155), and the complete AWA-style command presentation (#159).

```sh
curl -fsSL https://raw.githubusercontent.com/robertelee78/agent-memory/main/install.sh | bash
am --version
am --help
am update --check
am update
am uninstall --check
am uninstall
```

The default bootstrap follows the trusted managed `main` channel. Repeating it
updates an existing managed installation through the same ownership, fast-forward,
compatibility and recovery guards as `am update`. Explicit installation-target
configuration retains the ordinary separately previewed install operation.
No command modifies an unrelated development checkout or migrates project banks.

`am`, `am help`, `am --help` and `am -h` show public help. `am --version`, `am -V`
and `am version` agree. Lifecycle and diagnostic commands print readable output;
`--json` returns the complete existing machine result, and `--verbose` adds
detail. Packaged Python helpers remain JSON entrypoints. Agent-facing memory
operations retain their complete structured proposals and results.

`agent-memory` remains an owned compatibility command. Old installations can
use `agent-memory update` followed by `agent-memory install`, or repeat the
default one-line installer, to refresh the owned command set. Unrelated commands
cause refusal; user-modified targets remain preserved and visible. Uninstall
removes only verified ownership and preserves repository memory and user data.

Qualification is local and source-bound: actual default-output user journeys,
explicit JSON consumers, native macOS temporary aliases, operator-controlled
Linux, and execution of the actual old updater. Actual results, versions, source
identity, artifact hashes and retained limits belong in the published release
evidence. This corrective release does not claim a new complete hosted matrix
run from its focused checks. A published release and verified AWA milestone
close are required before calling the release delivered.

The readable bank schema stays `agent-memory/v1`; no schema migrator, personal
memory, cross-repository federation, MCP, harness hooks or signed distribution
is introduced. Later plans are preserved under ADR-0013's roadmap mapping.
