# v0.0.15 — Unreleased changes

## Checked semantic pages without repeated reconstruction (#209)

`am semantic inspect-v2 --pages-dir ABSOLUTE_NEW_DIRECTORY` can persist the exact
checked pages produced by one inspection. Reading that private bundle avoids
rebuilding the complete frontier for each page. Independent `page-v2` and default
no-flag inspection keep their existing behavior; review, publication and refresh
still perform fresh source, authority, policy, known-hold and recovery-frontier
checks. A completion marker proves artifact completeness, not currentness or
permission. Private output is exclusive, owner-only, no-follow, bounded and
verified by readback; partial output cannot become a successful bundle.

The daily-use controller consumes and verifies actual page items in both export
and baseline page modes. It retains original semantic/recovery controls, supports
reusing project/developer fixture identities, and records command monotonic
start/end times. The third-capture query correction avoids UUID substring
artifacts without skipping matches or enlarging limits.

Focused local checks passed five export contracts, nine existing semantic
contracts and a twelve-command public export/review/publication/peer-refresh
smoke with exact independent-page agreement and feature/index/HEAD preservation.
These are development results, not a claimed full stress/platform acceptance,
release delivery or measured whole-workload percentage improvement.

## Source-preserving recovery and native instruction context (#244, #249)

Known-owned ordinary transaction markers can exceed the unknown-marker read
limit only when their complete finite bytes match the executing transaction's
witness. Unknown markers and recovery sentinels retain their existing bounds
and no-follow, single-link, stable-parent checks. Actual direct admission and
interrupted recovery preserved earlier learning and staged feature/index/HEAD.

Native activation inventories held layout banks even before omp enrollment.
An unresolved hold still forbids assessment completion; it does not grant a
no-learning shortcut. Runtime compatibility combines layout and native-source
obligations rather than clearing one with the other's drain.

A fresh, exact receipt-owned full skill read is retained as metadata-only
operating-instruction context. Other tool results remain screened source data;
historical gaps are not waived. A crash before pure-control cursor publication
cannot route later ordinary source into a sealed parent; the orphan remains
an explicit inventory fault. These are scoped implementation and controlled
consumer results, not full native/platform or release acceptance.

Unrelated sibling creation/removal no longer invalidates a receipt-owned manual's
ancestor-directory witness. Directory identity, ownership and mode remain pinned;
manual bytes, owned link, receipt and artifact checks remain unchanged. Three
complete controlled consumer workers passed after this fix; this is not a claim
that native session coverage passed.

The public-synthetic hosted journey published a governed memory-only commit and
an independent native peer recalled both constraints, preserving staged feature
work and the publisher's index/HEAD. A separate actual short-print trace exposed
observer work never launched before normal native exit. That shutdown blocker
remains open; publication/recall success does not prove source coverage.
