# v0.0.15 — Lean `am`

v0.0.15 rebuilds agent-memory as one small Rust `am` per the operator's
[lean design](../design/v0.0.15-lean.md): a fresh agent quickly learns what the
project is, how it is built and its lessons, from plain Markdown in
`memory-bank/`, shared through Git. Memory never makes the user wait.

## Commands

| Command | Behaviour |
| --- | --- |
| `am install` / `update` / `uninstall` | Signed release (install.sh verifies the binary, `am` verifies the release-v2 manifest and pack), owned files only, recorded in a receipt. Takes over a v0.0.14 installation. |
| `am status`, `am doctor` | Installed? Hooks present? Bank healthy? Problems in plain words; doctor never rewrites memory. |
| `am init` | Create `memory-bank/` from the template. |
| `am recall [QUERY]` | The project summary plus the matching notes. |
| `am remember` | Write an approved note (flags or stdin JSON), skipping duplicates, linked in `MEMORY.md`. |
| `am share` | Commit only `memory-bank/` changes on the shared branch and push; a protected branch gets a memory branch and a pull request. |
| `am refresh` | Merge others' memory into the working tree without touching code or HEAD; the shared `memory-bank/` is staged so a plain `git pull` works. |

## Hooks

Claude and Codex get a `SessionStart` hook and omp a small extension; each
injects the project summary and how to use `am recall`/`am remember`. Nothing
runs at the end of each turn. The skill tells the agent to suggest a memory at
milestones (a confirmed fix, a decision, a finished task, a correction), ask the
user and only then `am remember`.

## Removed

Per-turn seals, sources, streams, nonces, clock windows and wake diagnostics;
layout recovery, frontier, holds and recovery queues; authority proofs, source
fingerprints and review receipts; repeated identity/config/bank re-checks; the
OpenCode turn plugin; every unit/contract test and the obligation ledger.

## Upgrading from v0.0.14

Re-run the one-line install. Each file the v0.0.14 receipt owns is replaced or
removed only while it is unchanged since installation: skill links, activation
blocks, the Python wrappers, the prompt/Stop hook entries (replaced by the
session-start hook), the OpenCode plugin link and the Python source tree.
Existing memory banks keep working unchanged.

## Quality

No unit tests. `scripts/qa.sh` drives the real `am` as a user would in a
temporary HOME and records each command's result and time.
