# v0.0.8 — Repeatable turn boundaries

Codex now retains each observed submission separately, including identical
follow-ups within one active turn. A completed assessment belongs to its exact
observation and digest; a valid pre-final completion allows Stop to finish quietly.
Older pending sources remain discoverable without being attributed to a new turn.

Claude retains native prompt evidence before asynchronous transcript publication.
OpenCode retains native session/message identifiers for pending work. Each adapter
preserves the substantive task answer when memory is unavailable, limits automatic
continuations, and keeps unsupported or interrupted work explicitly pending.
No-learning does not require creating a durable memory record or private workspace.

The quick refresh path now accepts an exact receipt-covered imported snapshot,
including deletions, while retaining fresh authority checks and preserving feature
HEAD and index. Unrecognized edits, staged memory, incomplete receipts and changed
authority remain refused rather than being silently adopted.

The release implements independently reviewed ADR-0020. Canonical memory remains
in each repository's Git-tracked bank; source observations and completion receipts
are private runtime evidence. Consumer installations do not inherit this project's
development memory. Qualification evidence is recorded separately before publication.

Native qualification covers Codex 0.165.0, Claude Code 2.1.306 and OpenCode
2.1.3. Source observations are not semantic truth: unavailable original sources
remain pending. OpenCode's configured GLM provider also stalled without this
plugin; successful ordinary native turns were verified with Kimi K3. The native
client may expose a generic server error when a prompt hook safely refuses unsafe
state; the retained qualification report describes the exact failure and recovery
limits rather than claiming an invisible or universally automatic workflow.
