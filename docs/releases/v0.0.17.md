# v0.0.17 — precise `am recall`

A small fix release of the lean `am`.

## Fix

`am recall QUERY` now prints only the notes that match the query.

- The project summary is no longer printed in front of the notes. Before, every
  search began with about 85 lines of summary.
- A note is returned only if it has every query word. Before, one word was
  enough.
- Words under four letters and numbers match exactly, so `service 17 port` no
  longer returns services 1, 170 and 171. Longer words still match their longer
  forms: `test` finds `tests`.
- Common words such as "the", "no" and "how" are ignored.
- When no note has every word, the closest notes are shown and the heading says
  so. When nothing matches, `am` says that.

`am recall` without a query is unchanged: it prints the project summary and the
list of lessons.

## Getting it

Run `am update`, or the one-line installer:

```sh
curl -fsSL https://raw.githubusercontent.com/robertelee78/agent-memory/main/install.sh | sh
```
