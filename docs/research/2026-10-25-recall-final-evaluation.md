## Semantic navigation and its growth curve

Sixteen fixed plain-language questions cover paraphrases, continuation markers,
component/session/prerequisite conditions, corrections, duplicates with independent
evidence, yellow/blue disagreement, absent knowledge, hidden/unsafe replacement,
expiry and HEAD versus staged code. Real `claude -p` calls interpret actual maps
and qualified records through public start/node/read operations. Opaque record
paths and expected labels are withheld until scoring. The actual provider reports
`claude-opus-5-5`; this is a custom portable-skill fixture harness, not a claim of
native Claude/Codex/OpenCode integration or the requested independent release review.

All nine positive questions find their labeled current records at each size in
the completed observations. Two related-but-irrelevant records are selected at
1k, two at 10k, and four at 50k. They stay counted as extras even when the model
labels them related context and asks for missing prerequisite/session information.
No returned extra bypasses native trust, validity, project or condition gates.
The report therefore supports preserved useful retrieval with imperfect semantic
precision, not a perfect answer engine or universally complete bank search.

The original 10k cohort completes fourteen cases, then its controller asserts when
the model's final path names an expired source that the native qualifier already
excluded. The model rationale itself says the source is invalid, but its structured
path list is inconsistent. The controller rejects it; no rejected source becomes
current guidance. This is retained as a model-selection/controller failure, not
an empty-result success. The controller now records such failures instead of
aborting the remaining cases. A separately identified two-case rerun completes
expiry and HEAD-versus-staged with no misses/extras. It does not erase the original
failure or supply the original aborted fixture's missing final preservation check.
A post-failure audit does verify the original candidate source remained exact.

The 1k and 50k cohorts complete all sixteen cases and preserve bank, feature edits,
Git index and HEAD. Current semantic runs have no model budget exhaustion. Earlier
50k runs did exhaust the model budget on three questions; those raw results remain
retained. The [scope-navigation correction](2026-10-25-semantic-parent-scope-routing.md)
and recall-only guidance avoid expanding branches whose inherited applicability
cannot hold in supplied context. This guidance cannot shortcut comparison/sharing.
Earlier [map coverage misses](2026-10-25-semantic-map-coverage.md) likewise remain
visible; source-derived map improvements preserve facts, conditions and provenance.

## Native cost, context and limits

| Lessons | Warm qualifier seconds | Warm whole navigation seconds | Cold rebuild qualifier seconds |

The cost controller has known selected paths and is explicitly not blind semantic
quality evidence. It measures actual public operations against the same hierarchy,
including complete canonical hash qualification on warm requests. At 50k the
semantic corpus has 50,843 files and 59,047,173 bytes; warm qualification reads
59,048,144 canonical payload bytes in 50,844 file reads and parses one selected
record. These counters exclude filesystem metadata, Git and audit I/O. Selected
qualified context is 1,766 encoded bytes. Cold setup (109.7 seconds) and cold
rebuild remain separately visible; there is no claim that all first-use work fits
five seconds. Ordinary non-discovery recalls do not publish optional catalogs.

The semantic data records every model call's actual input bytes, provider token
usage, reported dollar cost and public helper elapsed time. Model reasoning and
repeated full prompts make that custom workflow substantially more expensive than
one native qualification. Neither the known-path cost controller nor the actual
model workflow is passed off as direct semantic CLI support or semantic omniscience.

No required vector store, bank migration or personal memory is introduced. No
project, trust, validity, provenance or applicability relaxation buys the measured
speed. Bounded selected disclosure and independently reviewed native controls
remain in place. Follow-up work should improve semantic precision, consistent final
structured selection, map quality and cold discovery cost, using these retained
failures rather than raising corpus counts as an accumulation goal. #99's required
multi-session schedule and final signed release remain separate work.
