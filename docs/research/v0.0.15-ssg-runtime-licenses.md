Evidence classes, kept distinct throughout:

- **Observed** — a recorded command ran and its output is retained.
- **Declared** — a license statement made by metadata (dpkg copyright `License:`
  fields, Python `License`/`License-Expression`/classifiers, GGUF
  `general.license`, model cards, repository LICENSE statements). A declaration
  is not verification of what the code actually is.
- **Verified (byte identity only)** — equality of SHA-256 across independent
  copies, dpkg's own md5 consistency, image/container/tag-to-commit binding.
  No binary was rebuilt from source; nothing here verifies code origin,
  linkage, or reproducible builds.
- **[INFERENCE]** — reasoning from observed facts, marked where used.
- **Prerequisite** — not observed; never counted as a pass.
