`a31f4343095ea2dc11e45b47b7d0ec3fa2532186`, not acceptance of #98 or v0.0.3.

## Product gap and repair

The prior fixed corpus gave every route a generic caption and grouped records by
insertion order. Faster literal matching plus a blind synonym-query example did
not demonstrate semantic recall or finding a duplicate before a durable write.
Keep those genuine earlier measurements, with their original scope.

The operator confirmed both semantic entry points are useful, then explicitly
prioritized use inside Claude, Codex, OpenCode or another harness. The
[approved primary design](../design/v0.0.3-semantic-navigation.md) uses the current
harness to interpret meaningful topic descriptions. No nested production model
runner is needed for that path. A compact checked observation binds its map/source
choices to current Markdown; actual recall/comparison still enforce existing
source, currentness, applicability and provenance rules. Admission can place new
learning under agent-reviewed meaningful native topic nodes rather than append a
generic root caption. Standalone semantic search remains follow-on work.

Independent implementation review found three defects that initial passing
contracts had missed: a discovered source could be omitted from comparison; an
empty traced recall could fall through to the legacy inventory selector; and a
stable ID could unnecessarily require historical versions in a current trace.
The repaired implementation automatically includes discovered plausible sources
in comparison, uses exact discovered recall sources with empty meaning empty,
and qualifies the actually discovered version while retaining full invalidation
checks. Repaired-source macOS controls passed all 8 discovery and 13 reader
methods. The earlier source separately passed 14 admission, 11 comparison and
5 initial discovery methods; these are separate source-bound cohorts.

## Actual blind workflows

A separately identified informative fixture has 1,000 distinct lessons,
1,063 canonical files and 1,186,565 bytes before local identity binding. Its 31
root routes describe authored source subjects. The invoking Claude model received
the task, portable instructions and actual bounded map/source results, with no
expected paths/answer labels. The fixture controller exposed allowed navigation
and actual portable helper operations; it did not supply a synonym oracle or a
scripted semantic judge. This is a custom harness using real Claude reasoning,
not a claim of native Claude agent tool integration.

- **Recall:** “How often may a temporary network error be attempted again?” The
  model read the request-reliability group and its leaf, requested three plausible
  sources, received two qualified sources (one was withheld for an unknown
  prerequisite), then selected the actual bounded-retry lesson. No literal-search tool
  was exposed for that run. The producer checked source/bank, staged code, index
  and HEAD preservation. Five model calls took 25.81 seconds; provider-reported
  aggregate list cost was $0.6814562.
- **Before durable admission:** A differently worded observation described three
  transient repetitions, exponential waits, retained identity and immediate
  permanent-validation failure. The model navigated first, then supplied supporting
  comparison searches and classified the actual existing lesson equivalent.
  Public admission preview returned `update-existing` with no new proposal;
  actual governed consolidation reused the stable identity and retained the new
  observation's body/origin as historical provenance. The producer checked staged
  code/index/HEAD preservation. Four model calls took 30.64 seconds; provider-
  reported aggregate list cost was $0.6026104. Private capture classification
  occurred before discovery; semantic comparison preceded any durable bank write.

The initial duplicate-run controller stopped on a Markdown-wrapped JSON model
response before review/admission. Its raw response/failure remains retained. The
repair only accepts an entire json fence around a complete JSON object; a fresh
World/model run produced the completed observation above. That initial run is not
a product pass or evidence that semantic understanding failed.

## Cost and evidence limits

The costs above include repeated prompts in fresh `claude -p` calls. The initial
controller-format attempt separately consumed four model calls and provider-
reported $0.6131024; all thirteen recorded model calls across these attempts total
provider-reported $1.897169, with failed-attempt usage retained in the data. They do not
establish warm-session cost, final billing or an efficiency pass. Measure cumulative
request/context and cache usage, not just selected output. Reported reader metrics
include full canonical observation payload reads, not complete OS I/O; comparison,
transaction, audit and transport costs are not all instrumented by these metrics.
The current source checks still scan the complete bank. Small disclosed context
must not be described as constant-cost reading.

Expected source labels were scored after the model finished. Private raw prompts,
model/helper output and before/after producer source bindings are retained. The
first apparatus recorded helper/exit/time but not complete actual helper argv/env;
producer preservation assertions and verified transaction readback are not an
independent later filesystem audit after the disposable World has closed.

The separate fixture generator can construct 10,000/50,000-lesson maps within
native bounds (11,765,829/59,036,567 bytes), but those sizes have not yet completed
these semantic workflows. Broader conditions, cross-topic equivalents/conflicts,
hard negatives, changed-source controls, actual ongoing map maintenance and the
larger workflows still require evidence. Neither two examples nor structural
validity establishes universal semantic completeness or absence of degradation.
