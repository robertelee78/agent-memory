## API and ownership

Acceptance tests use `mod support;` and `support::World`. The `world` module exports:

- `World::new()`, public `root`, `token`, `paths`, `env`; `inside(path)`; idempotent `close()` and unwind-safe `Drop`.
- `run(argv)`, `run_with(argv, RunOptions)`, `git(argv)`, `git_with(argv, RunOptions)`, `am(argv)`, `am_with(argv, RunOptions)`, `helper(script, argv)`.
- `command(argv, RunOptions) -> Command`, with reusable `Command::run()`.
- `spawn(argv)` / `spawn_with(argv, RunOptions) -> Child`; `Child::wait()` consumes the one terminal result, `Child::close()` cancels/reaps idempotently, and `Drop` closes. Default spawn does not interpret a nonzero exit as an exception; run does.
- `repository(name, bare)` and `clone(remote, name)` use real Git, explicit argv, main as initial branch, and local-only transport.
- `require_world(&Environment, cwd)` permits explicit injected worker context; `require_current_world()` covers the baseline's current-environment branch without global mutation.
- `RunOptions`: cwd, fault-only env overrides, check, finite timeout, bounded capture, baseline group selector. Results are foundation `Output` byte vectors and typed `WorldError`, retaining process status, captured evidence, and collection failures.

No function accepts a shell command string. `am` executes the Cargo-built real binary using `env!("CARGO_BIN_EXE_am")`, retaining its installed-name entry behavior. `helper` additionally selects `--json` so legacy machine-oriented fixtures retain structured output even for human-default lifecycle routes.

The old borrowed `Group<'a>` could not safely reside in World while borrowing temporary argv/environment/cwd. The append-only foundation API resolves that prerequisite without imposing declaration/drop ordering on callers: `spawn_owned(&Spec<'_>) -> OwnedProcess` calls the existing private spawn path, owns only retained argv0 and pending byte input, and moves all existing child/pipe state. `Active::with_payload` moves fields with a new input-slice lifetime; there are no self-references, leaks, detached threads, unsafe additions, or copies of the full argv/environment/cwd into the retained handle. The owned input is attached only during synchronous collection.

`OwnedProcess::finish(Deadline)` delegates to the existing one-child `Group`/`consume_one` machinery; its effective deadline is the minimum of the original absolute Spec deadline and the supplied deadline. It never widens the original deadline. World records that same absolute deadline at spawn: it is enforced when collecting; while the caller is doing other synchronous work, close/drop still cancels the owned child rather than starting a background timer thread. Ordinary `run` retains the existing `run_for` launch-relative timer. The new API accepts all existing stdin kinds, passed descriptors, and descriptor output targets without silently coercing them: those descriptors are consumed/duplicated by the unchanged spawn path, not borrowed by the returned handle. Pending `Input::Bytes` is copied once because it must outlive the caller.

World holds shared cleanup control, not a borrow into the caller's Command or its own environment. A handle can outlive World; after World closes it is inert. Dropping a Child also collects it immediately. World prunes collected controls and refuses a fourth active child rather than extending the existing three-slot termination-registry model. The foundation extension uses the existing registry reservation and signal masking unchanged; no PID/group guessing or alternate child spawn path is introduced.

## Isolation and bounds

- Root is created atomically at mode 0700 directly under canonical `/tmp`, ignoring caller TMPDIR. The fourteen baseline directories are each 0700. A 48-hex-character token contains 192 random bits sourced from the host UUID primitive with fixed UUID nibbles removed; `.test-world.json` keeps the baseline JSON marker shape.
- Environment keys exactly match `tests/world.py` minus the two PYTHON variables. No parent environment is merged. HOME, all XDG/harness/private roots and GH_CONFIG_DIR remain under the world. Git author/committer are always `Test Developer <test@example.invalid>`, prompting/askpass are disabled, and Git transport is restricted to `file`.
- PATH is deduplicated am-directory, discovered Git-directory, optional private node-tools directory, `/usr/bin`, `/bin`. Optional Node is a private symlink to the discovered executable, as in the baseline.
- Git global/system configuration point to empty world-owned files in `credentials/`, not host configuration or credentials. This is a deliberate isolation-strengthening delta from baseline `/dev/null`, preserving empty-config behavior while keeping configuration paths inside the world.
- Capture is at most 8 MiB per stream; callers can request a smaller bound, not a larger one. Default timeout remains 60 seconds; deadline overflow is rejected before spawn. Marker reads are bounded at 4 KiB through the no-follow foundation reader. Regression fixture reads are bounded at 64 KiB.
- `inside` uses foundation canonical resolution, including intermediate symlinks and nonexistent suffixes, before checking world containment. Traversal, external absolute paths and symlink escapes refuse. Foundation's 40-symlink resolution bound replaces unbounded interpreter-dependent resolution.
- `require_world` rejects root symlinks/live paths, missing or symlinked markers, mismatched tokens, missing or external root variables, and cwd outside the world.
- Explicit close attempts every owned-child collection and temporary-directory removal before returning the first failure. Drop makes the same cleanup attempt without panicking during unwind. Collection/infrastructure/capture/deadline failures are never converted into success by `check=false`.
